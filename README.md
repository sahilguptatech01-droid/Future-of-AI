# FUTURE/AI — The Future of AI Agents

A responsive React + Vite + Tailwind website with a restrained midnight/blue visual system.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Hero animation integration
`src/components/hero/AnimationPlaceholder.jsx` is intentionally empty. Replace only its returned `div` with your own scroll-driven React animation. The reserved area is a plain dark surface and receives no animation, media, text, cards or placeholder artwork.

## Notes
- JavaScript (no TypeScript)
- React, Vite, Tailwind CSS, Framer Motion dependency included, Lucide React
- No backend, database, authentication or API integrations
- Impact photography is loaded from Unsplash URLs and uses lazy loading
- Navigation anchors, responsive mobile menu and reduced-motion support are included
